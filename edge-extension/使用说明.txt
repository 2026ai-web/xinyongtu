新龙图 Edge 侧栏 v0.12.1 测试版

安装：解压整包并双击 install.cmd，跟随提示首次加载固定目录。以后双击桌面“新龙图更新”，完成后在 Edge 扩展页点重新加载。无需手工覆盖目录。旧插件先停用保留，新固定路径不会迁移旧扩展数据。

使用：日常 Edge 登录多多招财，打开 报表→商品推广总览页。打开本侧栏，填写店铺备注，选择昨天/近7个完整日/近30个完整日，点击“一键采集／继续”。任务自动选择报表“全部”、切换主统计日期、读取表格、翻页并逐条进入“查看详情”。不需要逐条点击或下载报表。

保存三类历史：全店24小时分时及当天商品明细；每条推广链接24小时分时；今日账户及商品快照。今日快照不是日结，也不代表持续后台更新。历史单链接分时与商品日汇总核对；托管未提供的花费保留为空，不能记零或分摊账户差额。

商品 ID 与推广 ID 分开；同商品不同模式/推广 ID 分开保存。主日期和详情身份不一致、字段缺失、页数不全或采集期间数值冲突均暂停。页面加载或日期控件不受支持也会暂停，不能宣称已采全。点击“导出数据与诊断”可导出当前店铺仓库及最后诊断 JSON。

断点：已成功保存的数据集保留；同一天、同店铺备注、同范围再次点击可继续未完成任务。跨天或换范围新建任务。店铺备注不是平台身份认证，请保持登录同一店铺，切店前停止并更换备注。采集期间保持侧栏开启、目标标签选中，不要手动切换日期或筛选。关闭侧栏/电脑后不采集。意外关闭可能需等60秒锁过期。

本版仅读取已渲染报表，不修改预算/投产比/推广状态，不读取Cookie或密码，不上传商家数据。报表查询日期/模式/分页和查看详情属于自动采集动作。原单页功能在“高级”中，不能与一键任务同时运行。

一键仓库独立于旧版单页历史，最多20MB/5000数据集，满时停止不自动删除。导出备份后可用“清空采集仓库”清理全部店铺的一键数据；旧单页历史不受影响。
